## 재현 환경

- Linux, Python 3.12.14.
- 기존 시스템 패키지를 상속하지 않는 별도 가상환경에 `requirements-dev.txt`를 설치한 환경에서 실행.
- 명령: 해당 가상환경의 `python -m pytest -q`.
- JavaScript 문법 검사 `node --check static/app.js` 통과.
- Python 컴파일 검사 `python -m compileall -q app scripts run.py` 통과.

## 최종 브라우저 확인

지원되는 미리보기 브라우저에서 다음 흐름을 직접 조작했다.

1. 기존 매물 화면의 가상 매물 20개, 네 개 탭, 키 설정 대기, Zoro 미연결 표시.
2. 실행실 기본 조건으로 새 상담 생성·검색: 충족 6 / 확인 필요 3 / 제외 11.
3. 무계단 접근 선택지를 미지정으로 바꾸고 필수로 되돌리는 조작.
4. L001의 입구 계단 확인 작업 생성. 생성만으로 사실이 바뀌지 않음.
5. 계단 8개 입력 후에도 무계단 접근성은 미확인이고 확인 필요 후보 3개 유지.
6. 별도 무계단 접근 작업에 불가를 입력하면 L001이 제외로 이동: 충족 6 / 확인 필요 2 / 제외 12.
7. 입주 가능 시점을 2026-11-25 15:30으로 바꾸자 청소·이사 관련 충돌 2건 표시.
8. 등록된 시간표에서 일정 대안 3개 생성. 적용 전 기존 일정 유지.
9. 후보 재검색으로 대안이 지워졌을 때 ‘불가능’이라고 오표시하지 않고 재계산 안내.
10. 대안을 다시 만들어 첫 안을 적용: 청소 15:30~18:30, 이사 19:00~22:00, 충돌 없음.
11. 새로고침 후 기억된 상담 ID를 불러와 버전 10과 변경된 일정·기록 복원.
12. 적용 결과와 변경 이력을 실제 스크린샷으로 확인.

버전 충돌·계약 완료 제외·상담 격리·실행 실패 원자성은 자동 통합 검사로 확인했다. 이 항목을 모두 브라우저로 반복한 것은 아니다. 데스크톱 브라우저 검사이며 모바일·Windows 실기기 검증은 하지 않았다. 기존 v0.1 브라우저 기록은 `VERIFICATION_V01.md`에 보관했다.

## 독립 검토에서 수정한 문제

- 명시적으로 `conditions: null`을 보낸 새 상담이 생성되던 문제: 생략과 null을 구분하도록 HTTP 입력 모델 수정, 회귀 검사 통과.
- Content-Length만 검사해 실제로 큰 청크 본문이 통과할 수 있던 문제: ASGI 단계에서 실제 수신량 64KiB 제한. Uvicorn 파서 재현도 413·저장 0건 확인.
- 무계단 선택지의 잘못된 HTML: 미지정 옵션 수정 후 브라우저 선택 확인.
- 기존 일정 대안을 무효화한 뒤 ‘가능한 대안 없음’으로 표시하던 문제: 표시 상태 초기화, 브라우저에서 중립 안내 확인.
- 상담 재개 안내: ID 보관과 같은 폴더의 DB 유지 필요성을 화면·시작 문서에 추가.

검토 문서에 남은 실패 결과는 수정 전 재현 기록이다. 최종 결과는 이 문서의 542개 통과를 기준으로 한다. 더 큰 일정으로 확장할 때의 조합 탐색 비용 보완은 `REVIEW_SCHEDULE_V2.md`에 기록했다. 현재 공개 경로는 고정 세 작업만 사용한다.

## 실제 API 확인 상태

이 작업 환경에는 사용자 인증키가 없다. 실제로 `scripts/check_api.py --kind both --lawd-cd 11680 --month 202610`를 실행했을 때 두 서비스 모두 **NOT_RUN / MOLIT_KEY_MISSING**이었다. 네트워크 요청을 보내지 않았고 `both_apis_verified=false`인 보고서를 생성했다.

사용자가 로컬 키 입력 도구에서 키를 저장하고 실제 호출을 선택하면 두 API를 각각 한 번씩 검사한다. 보고서에는 검사 시각·상태·건수·정해진 경고만 남긴다. 정상 0건은 개별 거래 필드 매핑을 검증하지 못하므로 거래가 있는 월에서 다시 확인한다. 공개 API 문서의 개별 item 필드와 실제 응답 대조도 첫 인증 호출 후 남아 있다.

## 산출물과 남은 범위

배포 검사는 실제 생성한 ZIP을 별도 폴더에 풀어 기존 화면·자료 조회·새 상담·검색·서버 객체 재생성 후 SQLite 복원을 수행했다. 인증키·런타임 DB·검증 보고서·가상환경·모델 가중치는 배포 대상에서 제외했다.

미검증/후속: 사용자 키의 실제 국토부 응답, Windows 실기기 키 입력 및 권한, 실제 GPU·Zoro 추론과 행동 선택, 상충하는 복수 출처 주장 처리, 업체 요청 초안. 실제 예약·메시지 발송·공개 배포는 수행하지 않았다.
