# 전체 통합본 v0.4.2 검증

2026-11-15. 덮어쓰기 없이 새 폴더에서 실행할 수 있도록 최신 앱·GPU 연결 도구를 한 ZIP에 통합했다. ZIP 최상위에 `START_WINDOWS.cmd`가 있다.

## 검증 결과

- 새 시작·설정 가져오기·기존 설치 관련 검사: 39개 통과.
- 전체 오프라인 검사: **1,219개 통과, 실패 0개**. 위 39개와 이전 검사 수를 중복 합산하지 않는다.
- 기존 개발 모드 HTTP 시나리오 **20/20 통과**. 실제 모델 성적으로 해석하지 않는다.
- 완성 ZIP을 새 임시 폴더에 풀어 Linux에서 실행했다. v0.4.2 상태 응답, 홈페이지, 새 상담 생성, 예산 누락 시 추가 질문이 실제 HTTP로 동작함을 확인했다. 개인 키와 기존 상담 DB는 사용하지 않았다.
- 변경한 시작 스크립트의 Python 문법 검사 통과.
- 설정 가져오기는 사용자가 선택한 폴더의 국토부 인증키만 복사한다. 기존 코드·상담 DB·Zoro 주소는 옮기지 않으며 원본 설정과 DB가 보존되는 사례를 검사했다.
- 빈 키·잘못된 설정·심볼릭 링크·키 입력 취소는 실제 API 검사를 시작하지 않도록 검사했다.
- API 검사 실패는 성공으로 표시하지 않으며, 서버는 예시 자료를 사용할 수 있도록 계속 시작한다.
- 브라우저는 이번에 실행한 서버 객체가 준비됐을 때만 연다. 이전 앱이 같은 포트를 사용해 새 서버가 시작되지 못한 경우에는 새 앱이 실행됐다고 오인하지 않도록 했다.
- 새 ZIP이 최상위 실행 파일과 앱·데이터·연결 도구를 모두 포함하고, 실제 키·런타임 DB·가상환경·보고서를 포함하지 않는지 검사했다.

검사 환경은 Linux/Python 3.12. Starlette/httpx 사용 변경 예고 경고 1건이 있으며 기능 실패는 없다.

## 검증 범위 밖

Windows 실기기에서 CMD와 새 설정 창을 직접 실행하지 않았다. 실제 국토부 조회 성공은 사용자의 기존 환경 보고와 구분한다. 실제 Vast GPU 설치·Zoro 추론·응답 속도 검증도 아직 하지 않았다. 이번 ZIP은 앱 전체와 연결 준비 도구를 포함하며, 모델 파일과 개인 키는 포함하지 않는다.
