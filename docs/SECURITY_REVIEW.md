# 설정·자료 경계 검토

검토일: 2026-11-12. 검토 대상은 준비 단계 1~4 코드다. 실제 국토부 인증키, 고객 개인정보, Zoro 서버 접속 정보는 사용하지 않았다.

## 코드에서 확인한 사항

| 항목 | 확인 내용 |
|---|---|
| 비밀 설정 | `Settings`의 인증키·Zoro 주소 필드는 `repr=False`. 상태 API에는 설정 여부만 공개한다. |
| 설정 파일 | 프로젝트 루트 `.env`만 읽으며, 환경변수가 파일 값보다 우선한다. 파일 내 변수 치환은 비활성화되어 있다. |
| 파일 공개 범위 | `/`는 지정한 HTML, `/static`은 정적 폴더만 제공한다. 프로젝트 루트를 정적 폴더로 노출하지 않는다. |
| 제출 파일 | `scripts/build_package.py`는 루트 파일 이름과 하위 폴더별 확장자 허용 목록으로 포장한다. `.env`, 가상환경, 캐시와 심볼릭 링크를 제외한다. |
| 실호출 대상 | 국토부의 두 HTTPS 주소가 코드에 고정돼 있다. 사용자 입력으로 목적지 호스트를 바꾸지 못한다. |
| 인증키 전송 | 서버 HTTP 쿼리에만 사용한다. percent encoding은 HTTP 클라이언트가 처리하며 `+` 문자를 보존한다. |
| 리다이렉트 | 자격 증명을 다른 주소에 전달하지 않도록 따라가지 않는다. 환경 프록시도 기본 클라이언트에서 상속하지 않는다. |
| 요청 제한 | 타임아웃, 페이지 크기, 응답 바이트 수를 제한한다. 인증·쿼터 오류에 대한 자동 재시도를 하지 않는다. |
| XML | `defusedxml`로 DTD·엔티티·외부 참조를 금지한다. 형식에 맞지 않는 행은 조용히 정상 자료로 바꾸지 않는다. |
| 오류·로그 | 외부 응답 원문이나 예외 문자열 대신 고정 메시지를 반환한다. HTTPX의 키 포함 요청 로그를 차단하고 로컬 실행기의 접근 로그도 비활성화한다. |
| 자료 출처 | `sample`과 `live`를 명시적으로 분리하고, 실호출 실패 시 가상 자료를 반환하지 않는다. |
| 브라우저 렌더링 | 외부 명칭·금액·오류·시나리오는 DOM의 `textContent`로 넣는다. API 키 입력란·브라우저 저장소 보관·외부 CDN 의존성을 두지 않는다. |
| 모델 상태 | Zoro 주소가 설정돼도 연결·검증 완료라고 표시하지 않는다. 현재 프로그램에는 실제 모델 실행이 없다. |
| 기본 노출 범위 | 기본 실행 주소는 `127.0.0.1`. 브라우저의 교차 사이트 API 요청을 거부하고, 프레임 포함을 막는 응답 헤더를 설정한다. |

## 실행해서 확인한 범위

독립 검토에서 `tests/test_config.py` **12개**, `tests/test_molit.py` **64개**가 통과했다. 이는 설정 값 검증·비밀 문자열 표시 방지·공통 키 설정·HTTP/XML 오류·변환 계약 등의 오프라인 코드 검사 결과다. 전체 통합 검증 수와 UI 검증 결과는 최종 검증 보고서가 기준이다.

검증에 사용한 문자열은 테스트용 가짜 값이다. 오프라인 테스트 통과는 실제 국토부 인증 성공, 최신 API 응답 호환성, Zoro 정확도 검증을 의미하지 않는다.

## 검토 중 발견해 반영한 수정

- 거래 항목이 모두 파싱 제외되었을 때 실제 거래가 없다고 표시하던 분기를 수정했다. `skipped_count`와 전체 건수를 구분해 안내하며 다음 페이지가 있으면 이동 수단을 유지한다.
- 이전 조회를 취소한 뒤 늦게 도착한 오류가 새로운 조회 화면을 덮지 않도록, 요청 식별자와 `AbortError`를 확인한다.
- 전월세의 취소 여부는 이 자료로 확인하지 않았다는 안내를 유지한다.

위 항목은 변경된 프런트엔드 코드에서 확인했다. 브라우저 조작에 대한 최종 확인은 통합 검증 결과에 별도로 기록한다.

## 사용 범위와 남은 확인

- 이 버전은 개인 컴퓨터에서 사용하는 준비용 서버다. `0.0.0.0`으로 열면 해당 네트워크의 다른 사용자가 접근할 수 있으므로, 외부 서비스로 운영하려면 인증·접근 제어·요청량 제한을 추가해야 한다. 현재 제공 범위는 외부 공개 서비스가 아니다.
- 실제 키를 넣은 `.env`는 `.gitignore`에서 제외한다. 제출 ZIP은 제공한 포장 스크립트로 생성하고, 실제 키를 예제 파일이나 소스코드에 옮겨 적지 않는다. 파일 제외 규칙은 소스코드에 직접 적힌 비밀까지 자동 탐지하는 도구는 아니다.
- 첫 실호출에서 필드·단위·해제 표식·페이지 정보는 [API_REFERENCE.md](API_REFERENCE.md)의 체크 항목으로 검증한다.
- 임대차 응답의 `cancelled=false`는 해제 여부가 실제로 확인되었다는 뜻이 아니다. 클라이언트의 별도 가용성 표시와 경고를 유지해야 한다.
- 화면의 데이터·일정은 합성 자료이며 실제 업체 예약·실제 매물 재고를 보장하지 않는다.
