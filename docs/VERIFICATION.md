# 검증 기록 — 집의 다음 v0.4

기준일: 2026-11-12, 한국 시간. 범위는 상담 대화, 기존 실행 도구, 상황 변화 후 재검사·일정 복구, 모델 어댑터와 평가 준비다. **실제 Zoro 추론·호환성·성능은 아직 검증하지 않았다.**

새 상담 화면의 pytest 실행기 1개 안에서 **Node 13개 사례**를 실행했다. 기존 거래 화면도 별도 Node 13개 사례를 수행한다. 이 수를 위 합계에 다시 더하지 않았다. Node가 없으면 화면 실행기는 건너뛰므로 완전 재현에는 Node도 필요하다.

`python scripts/evaluate_agent.py`는 **20/20 통과**했다. 모두 개발 모드의 실제 앱 HTTP 경로를 임시 DB로 실행한 결과다. 일부 live 처리 사례는 가짜 키·MockTransport·합성 XML이며 실제 국토부 인증 성공이 아니다. Python 컴파일과 두 JavaScript 파일의 문법 검사도 통과했다.

유일한 경고는 설치된 Starlette TestClient의 httpx 사용 변경 예고다. 기능 실패는 없었다. 실제 모델이나 인증 연결에 관한 성공 주장은 이 결과에서 도출하지 않는다.

## 병렬 작업과 독립 검토

6개 고추론 작업을 플래너, 모델 어댑터, 거래 근거, 상담 화면, 평가, 보안 검토로 나눴다. 통합 담당자가 세션 계약·도구 실행·승인·라우팅을 구현하고 전체 검사를 실행했다. 평가 담당자가 플래너를 다시 검토했고, 모델 담당자가 통합부를 별도로 검토했다.

검토에서 발견해 수정한 주요 문제:

- “조회하지 마”, 모호한 부정문, 미지원 필수 조건을 실행/저장 요청으로 오해할 수 있던 처리.
- “확인해줘”라는 요청을 이미 확인된 현장 사실로 기록할 수 있던 처리.
- 일정 선택에서 11번이나 부정된 첫 번째 선택을 첫 대안으로 해석할 수 있던 처리.
- 원자적 저장 후 내부·표시용 일정 대안의 버전이 달라질 수 있던 처리.
- 요청 한도 끝에서 더 이상 승인할 수 없는 새 변경을 만들 수 있던 처리.
- 수동 입력이나 저장된 대화에 들어간 설정 비밀값을 모델 요청 전에 검사하지 않던 경계. 국토부 키도 모델에 전달되기 전에 차단한다.
- 브라우저에서 발견한 잘못된 Zoro 선택 항목 HTML. 해당 오류로 전송이 비활성화되던 문제를 수정하고 실제 HTML을 검사하는 회귀 검사를 추가했다.
- 상태 조회 복구 후 옛 오류 문구가 남거나 오래된 요청 결과가 새 상태를 덮는 화면 처리.

## 실제 브라우저에서 확인한 흐름

데스크톱 Chrome으로 실행 화면을 직접 사용했다. 가상 자료를 사용했으며 실제 국토부/모델 요청은 이 화면 검사에서 수행하지 않았다.

1. 면적·무계단 조건을 말하면 저장 전 변경 카드를 표시했다. 승인 뒤 예산 누락을 질문했다.
2. `10억`으로 답하면 예산만 추가하는 확인 카드를 만들었다. 승인 후 충족 7개·확인 필요 4개·제외 9개와 내부 확인 요청을 표시했다.
3. `L001 무계단 접근 불가로 확인했어`를 승인하자 확인 필요 3개·제외 10개로 재분류했다. 다른 미확인 항목을 확인 완료로 취급하지 않았다.
4. 입주 가능 시각을 `2026-11-25T15:00:00+09:00`로 바꾸고 승인하자 충돌 2건과 대안 3개를 표시했다.
5. 첫 대안을 선택·전송·승인하자 청소 15:30~18:30, 이사 19:00~22:00로 바뀌고 시간 충돌이 없어졌다. 실제 예약을 했다는 문구는 없었다.
6. 가상 과거 전월세 3건을 조회하고 가상 출처·과거 계약·해제 미확인 표지를 확인했다.
7. 같은 세션의 실행실에서 동일한 후보·확인 기록·복구된 일정을 확인했다. 기존 실거래 조회 탭에서도 가상 전월세 표가 동작했다.
8. 페이지 새로고침 후 세션 이어가기로 버전 11, 대화, 조건과 복구된 일정을 불러왔다.
9. Zoro 설정이 없을 때 모델 선택이 비활성화되고 개발용 규칙 실행임이 표시됐다. 화면의 금액을 읽기 쉬운 억·만·원 형식으로 확인했다.

화면을 스크린샷으로 점검했다. 모바일 실기기와 이 버전의 Windows 직접 실행은 이번 검사 범위가 아니다. 사용자의 이전 Windows 버전/API 성공 보고와 구분한다.

## 국토부 실제 연결과 배포

사용자는 자신의 Windows PC에서 매매·전월세 실제 자료가 모두 잘 표시된다고 확인했다. 이전 작업 환경의 인증 조회는 네트워크 실패였고 이번 검사는 오프라인이므로, 두 환경의 결과를 별도로 기록했다. 상세 내용은 `LIVE_API_CHECK.md`에 있다. 키를 넣은 기존 폴더에 업데이트하면 설정을 유지한다.

배포 ZIP은 명시적 파일 허용 목록으로 만들며 키·첨부 이미지·런타임 DB·실행 보고서·가상환경·모델 가중치를 제외한다. ZIP 무결성과 파일 목록, 실제 설정 키의 포함 여부를 확인한다. 기존 `.env`와 DB를 보존하는 업데이트 순서는 `START_HERE_KO.md`에 있다.
