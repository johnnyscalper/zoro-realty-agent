# v0.4.1 검증 기록

2026-11-15. 기존 v0.4에 GPU 실행 준비, Windows 모델 설정, 실제 모델 통합 검사 실행기를 추가했다.

## 실행한 검사

- 연결 설정·모델 어댑터·패키징 대상 검사: 132개 통과.
- 전체 오프라인 회귀 검사: **1,201개 통과, 실패 0개**, 약 19초. 위 132개를 중복 합산하지 않는다.
- 새 스크립트 3개의 Python 문법 검사 통과.
- 실제 GPU를 사용하는 검사 실행기 자체는 가짜 모델 응답으로 검사했다. 기존 사용자 DB를 보존하고, 임시 가상 DB에서 후보 검색·확인 결과 반영·일정 대안 계산이 작동함을 확인했다.
- 잘못된 현장 확인 값을 제안하면 자동 검사 코드가 승인하지 않는 사례, 설정 갱신 시 국토부 키와 다중행 값을 보존하는 사례, 과대 응답·리다이렉트·인증 오류 처리 등을 확인했다.
- 공식 upstream의 소스 HEAD를 확인해 `3a7877868c63ff82af14f707a1018bc0baac0711`로 설치 도우미를 고정했다. 서버는 loopback에만 바인딩한다.

pytest 실행 환경은 Linux/Python 3.12. 기존 Starlette/httpx 사용 변경 예고 경고 1건이 있으며 기능 실패는 없다.

## 아직 하지 않은 검사

- 사용자의 Vast 인스턴스에 접속·설치·다운로드·GPU 추론을 수행하지 않았다.
- RTX PRO 5000에서 SGLang 설치·CUDA 커널 실행·속도·메모리 사용량을 검증하지 않았다.
- 새 Windows Zoro 설정 창과 CMD 실행기를 Windows 실기기에서 실행하지 않았다.
- 새 `check_zoro.py`의 실제 서버 3개 사례를 통과했다고 주장하지 않는다. 실행 시 결과가 별도 보고서에 남는다.
- 20개 기존 개발 모드 평가와 실제 Zoro 평가는 구분한다. 전체 Zoro 평가와 현장 시연은 후속 작업이다.

모델 서버의 `/v1/models`는 자기보고 ID다. 공식 모델 다운로드 기록·리비전과 함께 확인해야 하며 독립적인 모델 가중치 검증으로 표현하지 않는다. 앱은 Chat Completions를 통한 행동 선택을 사용한다. `/v1/decide` 헤드나 self-spec 속도 개선을 앱에서 활용·검증했다고 주장하지 않는다.
