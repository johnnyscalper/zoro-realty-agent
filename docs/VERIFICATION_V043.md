# 기본 상담 문장 v0.4.3 검증

2026-11-16. 결과 설명과 기본 인사·질문을 친절한 상담 문장으로 표시한다. 별도 모델 호출, 스트리밍, 새 업무 도구는 추가하지 않았다.

## 확인한 내용

- 전체 오프라인 검사 **1,231개 통과, 실패 0개**. 이 안에 신규 상담 회귀 검사 12개와 기존 개발 모드 HTTP 시나리오 20개가 포함된다.
- 인사 → 예산·조건 입력 → 변경 승인 → 후보 검색이 실제 앱 HTTP 경로에서 이어진다. 최종 설명의 후보 수는 도구 관측값과 일치한다.
- 친절한 화면용 질문과 내부의 원래 질문을 분리했다. `선호로` 같은 짧은 후속 답변이 기존 조건 해석으로 이어진다.
- 인사와 업무 요청이 함께 있는 문장은 인사 분기에 흡수하지 않는다.
- 승인 대기·취소·실행 실패·롤백을 변경 완료로 표현하지 않는다. 필수 조건을 임의로 완화하지 않는다.
- 미확인 항목, 가상 후보·업체, 실제 예약이 아닌 내부 일정이라는 구분을 유지한다.
- 거래 조회 설명은 검증된 서버 요약을 그대로 포함한다. 가상/국토부 출처, 제한된 조회 범위, 부분 결과를 보존한다. 테스트의 국토부 형태 응답은 모의 자료이며 실제 인증 조회가 아니다.
- 모델의 자유 문장이나 `finish.reason`을 완료 주장으로 표시하지 않는다. Zoro는 다음 행동을 선택하고, 최종 결과 문장은 앱이 구성한다.
- 기존 프런트엔드 회귀 검사도 전체 검사에 포함했다. 별도 Chromium 실화면 점검은 브라우저 실행 권한 제한으로 시작되지 못했으며, 화면 캡처 성공으로 기록하지 않는다.
- 완성 ZIP을 새 임시 폴더에 풀어 실제 앱 HTTP 경로(ASGI)로 버전·홈페이지·인사·조건 입력·승인·상담 결과를 확인했다. 시험 조건의 필수 충족 7개, 미확인 4개, 제외 9개가 문장에 표시됐으며 실제 모델을 호출하지 않았다. ZIP 최상위 실행 파일과 비밀 설정·DB 제외도 확인했다.

검사 환경: Linux / Python 3.12. 기존 Starlette/httpx 변경 예고 경고 1건이 있고 기능 실패는 없다.

## 전달 및 남은 확인

전체 ZIP은 새 폴더에서 실행할 수 있으며 앱·테스트·데이터·GPU 연결 도구를 모두 포함한다. 개인 인증키, 기존 상담 DB, 가상환경, 모델 파일, 실행 보고서는 제외한다. 이전 폴더에서 국토부 키만 가져올 수 있으며 원본 폴더와 상담 기록을 변경하지 않는다.

이번 버전의 Windows 실기기 실행, 실제 Vast GPU 설치 및 Zoro 추론은 아직 확인하지 않았다. 답변은 처리가 끝나면 한 번에 표시되며, 범용 장문 상담이나 실시간 글자 출력은 제공하지 않는다.
