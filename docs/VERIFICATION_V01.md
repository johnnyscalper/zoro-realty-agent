# 검증 기록 — 2026-11-12

대상: 집의 다음 v0.1 · 사전 준비 1~4단계. 이 기록은 Zoro 에이전트의 성능 평가가 아니다.

**오프라인 자동 테스트 180개 통과**, 실패 0개. 사용자 API 키나 GPU를 사용하지 않았다.

| 국토부 연결 코드 | 64 | 합성 XML 변환, 금액 단위, 해제 표시, 월세 구분, 정상 빈 결과, 인증·쿼터·연결 오류, 안전한 XML, 키 인코딩, 리다이렉트 차단 |

| 패키징 | 2 | 비밀 설정·가상환경·로그 제외, 심볼릭 링크로 외부 파일 혼입 방지 |

`data/scenarios.json`의 **20개 문제는 후속 평가 계획**이다. 위 180개 자동 검사의 개수와 다르며, Zoro가 20개를 풀어 통과한 결과가 아니다.

## 재현 환경

- Linux, Python 3.12.14.
- 기존 시스템 패키지를 상속하지 않는 새 가상환경에 `requirements-dev.txt`를 설치한 뒤 전체 검사를 실행했다.
- 명령: `python -m pytest -q`.
- 결과: `180 passed, 1 warning in 0.73s`.
- 경고: 현재 Starlette TestClient가 httpx 사용의 향후 변경을 알리는 deprecation 경고 1개. 테스트 실패나 런타임 API 오류가 아니다.
- 고정한 주요 패키지: FastAPI 0.141.1, Uvicorn 0.52.1, HTTPX 0.28.1, Pydantic 2.13.4, python-dotenv 1.2.2, defusedxml 0.7.1, pytest 9.2.0.
- 새 환경에서 해석된 하위 의존성: Starlette 1.10.0, anyio 4.16.0. 전체 의존성을 고정한 잠금 파일은 제공하지 않으며 주요 패키지 버전을 고정했다.
- JavaScript 문법 검사(`node --check static/app.js`) 및 Python 컴파일 검사 통과.

## 실제 브라우저에서 확인한 것

1. 첫 화면에서 가상 매물 20개와 평가 계획 20개, 키 설정 대기, Zoro 미연결 상태 표시.
2. 보증금 10억 원 이하·전용면적 75㎡ 이상·시연상 거래 가능 조건으로 9개 매물 필터링.
3. 보증금 5억 원 필터에서 0개 결과를 표시하고 조건을 임의로 완화하지 않음.
4. 가상 매물 상세에서 계단 8개·우회 경로 없음 등의 확인 자료 표시.
5. 전월세 예시 3건 조회, 보증금·월세 금액 변환과 전세/월세 표시.
6. 매매 예시 3건 조회, 해제 신고와 해제 일자 표시.
7. 실제 API 모드 전환 시 예시 결과 삭제, 키 미설정 안내와 조회 버튼 비활성화.
8. 시연 설계 탭에서 일정 선후 관계, 한국어 기대 행동, 선택적으로 여는 기술 입력 자료 확인.
9. 입력 레이블 연결을 수정한 뒤 정확한 레이블로 필터 조작 성공. 숨긴 탭의 장식 문자가 접근성 트리에 노출되던 현상 수정 후 사라짐 확인.

브라우저 검사는 데스크톱 화면에서 수행했다. 반응형 CSS는 포함했지만 모바일 실기기나 Windows 실기기 동작까지 검증한 것은 아니다. 브라우저 로그에는 확장 프로그램 자체의 metadata 전송 오류가 보였으나 위 기능 동작은 확인했다.

## 발견하고 수정한 문제

- 가상 데이터의 `notice` 필드를 서버 스키마가 거부해 상태·매물 조회가 실패하던 문제: 스키마를 맞추고 관련 테스트 재통과.
- 필수 항목이 모두 파싱 제외된 페이지를 ‘거래 없음’으로 표시하던 UI: 제외 자료·다른 페이지·실제 0건을 구분.
- 취소된 이전 요청 오류가 최신 조회 화면을 덮을 수 있던 문제: 요청 소유권 확인과 AbortError 처리 보완.
- 화면 자산 경로, 입력 레이블 연결, 숨긴 시나리오의 문자 장식 접근성 문제 수정.

## 아직 확인하지 않은 것

- 사용자 인증키로 두 국토부 API를 실제 호출하는 것. `check_api.py`의 키 미설정 실행은 두 종류 모두 `NOT_RUN`으로 종료했고 외부 요청을 보내지 않았다.
- 공식 상세 item 명세와 실제 응답의 대조. 공개 포털에서 확인된 엔드포인트·요청 변수·오류 규격과 달리, 항목별 필드·금액 단위·해제 일자 표현은 첫 인증 호출에서 다시 대조해야 한다. 합성 XML을 실제 국토부 결과로 제시하지 않는다.
- Zoro 모델 다운로드·실행·행동 판단·속도. 현재 설정값은 후속 연결을 위한 자리만 있다.
- 추천 재검증·일정 복구 자동 실행. 현재는 명세·데이터·평가 기준을 준비했다.
- 실제 예약·메시지 발송·외부 배포. 수행하지 않았다.

다음 검증은 `START_HERE_KO.md`에 따라 로컬에서 키를 설정하고 실제 조회를 확인하는 것이다. 키가 없는 상태에서도 후속 실행 기능과 Zoro 연결 코드 작성은 계속할 수 있다.
