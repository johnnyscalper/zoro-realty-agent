# v0.3 국토부 XML 클라이언트 독립 검토

검토일: 2026-11-12. 범위: `app/molit.py`, 기존 국토부 클라이언트 검사,
새 회귀 검사 `tests/test_client_v03.py`. 이 검토에서는 인증 HTTP 요청을
보내지 않았고, 실제 키 파일이나 사용자 업로드를 읽지 않았다. 아래 XML 검사는
모두 명시적으로 합성된 입력을 사용했다. 실제 호출 결과는 별도의 실조회 검증
기록을 따른다.

## 발견하여 수정한 문제

| 문제 | 기존 영향 | 반영한 수정 | 회귀 검사 |
|---|---|---|---|
| 오류 코드보다 `NODATA_ERROR` 메시지를 먼저 처리 | `resultCode=30`인데 메시지가 `NODATA_ERROR`인 응답을 인증 실패 대신 정상 0건으로 해석할 수 있었다. 후속 검증 보고서에도 정상 응답처럼 전달될 수 있었다. | 제공기관의 오류 코드를 먼저 분류한다. 표준 `03` 무자료 코드와 오류가 없는 `0`/무자료 메시지 조합은 정상 빈 결과로 유지한다. `04`는 오류다. | 일반 `header`와 게이트웨이 `cmmMsgHeader` 각각에서 인증·쿼터·시간 초과·서비스 오류와 무자료 메시지가 함께 올 때 오류를 유지하는 10개 사례. |
| 후속 페이지의 남은 건수·누락 검사가 불완전 | 20건씩 조회하는 2페이지에서 전체 21건인데 2건을 반환하는 모순을 허용했다. 전체 45건의 2페이지가 비어 있어도 정상 빈 페이지로 반환했다. | 페이지 시작 위치를 전체 건수에서 빼서 남은 위치를 계산한다. 그 범위를 넘는 행이나, 남은 위치가 있는데 비어 있는 페이지를 형식 오류로 거절한다. | 불가능한 후속 페이지 3개, 남은 행이 있는 빈 페이지 2개, 정상 마지막 페이지, 정상 범위 밖 빈 페이지 3개. |

정상 마지막 페이지의 전체 건수와 행 ID의 절대 위치는 유지된다. 전체 범위를
벗어난 빈 페이지는 계속 정상 처리한다. 형식 오류를 가상 거래로 대체하거나
인증 실패를 정상 0건으로 바꾸는 동작은 추가하지 않았다.

## 필드와 오류 경로 확인

| 항목 | 오프라인 확인 결과 |
|---|---|
| 매매 금액 | 만원 문자열을 `Decimal`로 읽어 정수 원화로 변환한다. 필수 금액 누락·형식 오류 행은 제외 건수와 경고로 남는다. |
| 전월세 금액 | 보증금과 월세를 각각 변환한다. 1원 단위에 해당하는 소수 만원 값도 반올림 없이 보존하고, 월세가 0보다 크면 월세 계약으로 구분한다. 매매 형태의 추가 필드가 전월세 금액을 덮지 않는다. |
| 계약 날짜·지역 | 달력 날짜, 조회 계약월과의 일치, 제공된 지역코드와 조회 지역의 일치를 검사한다. |
| 매매 해제 | 해제 표식만 있어도 해제로 유지하고, 해제일만 있어도 증거를 버리지 않는다. 지원하는 네 날짜 표현을 같은 ISO 날짜로 정리한다. |
| 전월세 해제 | `cancellation_status_available=false`와 별도 경고를 유지한다. `cancelled=false`를 유효 계약 확인으로 설명하지 않는다. |
| 정상 빈 결과 | 전체 0건, 범위 밖 빈 페이지, 명시적 무자료 응답을 형식 오류와 구분한다. |
| 실패 응답 | HTTP 실패, XML 내부 실패, XML/필수 페이지 필드 오류, 위험한 XML, 응답 크기 제한, 연결·시간 초과 처리를 기존 검사와 함께 확인했다. |
| 키 처리 | 기존 모의 HTTP 검사에서 Decoding/Encoding 키의 `+`·`/`가 한 번만 인코딩되는 동작과 리다이렉트 차단·비밀값 없는 오류를 유지했다. 실제 키를 사용한 검사는 아니다. |

## 공식 자료 대조와 남은 범위

공공데이터포털의 [아파트 매매 자료](https://www.data.go.kr/data/15126469/openapi.do)와
[아파트 전월세 자료](https://www.data.go.kr/data/15126474/openapi.do)는 각 현재
서비스 기본 주소, XML 형식, 법정동 앞 5자리와 계약년월 6자리 조회를 명시한다.
열람된 공개 응답 표는 `header`와 `body`까지만 제공하므로, 이 검토만으로 최신
개별 항목 명세를 공식 원문과 전부 대조했다고 볼 수 없다.

실조회 담당자는 성공/빈 결과의 페이지 정보, 매매·전월세 필드의 실제 값과
금액 단위, 매매 해제 사례 및 전세/월세 사례를 별도로 확인해야 한다. 이 문서는
인증 승인, 제공기관의 실제 개별 필드, 현재 매물 상태 또는 Zoro 연결을 검증한
기록이 아니다.
