# 현장에서 확인한 뒤 추천을 바꾸기

> 현장에서 L001의 무계단 접근이 불가능한 것으로 확인했어. 이 확인 결과를 반영해줘.

| 시점 | L001과 상담 상태 |
| --- | --- |
| 현장 확인 전 | 무계단 접근 가능 여부가 비어 있어 확인이 필요한 후보로 남았습니다. |
| Zoro의 제안 | `record_inspection`을 선택하고 테스트 사용자의 승인을 기다렸습니다. |
| 승인 후 | 앱이 확인값을 한 번 기록하고 필수 조건을 다시 적용해 L001을 제외했습니다. |

GPU 실행 로그에는 `one_confirmed_observation`, `listing_updated`, `candidate_excluded`가 모두 참으로 기록됐습니다. 승인 전 제안은 Zoro가 만들었고 승인 후 저장과 재분류는 앱이 수행했습니다. 같은 가상 자료를 다시 계산하면 확인 필요 후보가 3개에서 2개로, 제외 후보가 11개에서 12개로 바뀝니다.
